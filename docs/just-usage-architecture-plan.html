04 · Shared contract

The UI stays intentionally dumb.

Adapters translate provider responses once. Everything after that operates on one predictable shape.

type QuotaSnapshot = {
  account: {
    id: "codex:personal",
    provider: "codex",
    label: "Personal",
    plan?: "pro"
  },
  windows: [{
    label: "5 hours",
    usedPercent: 42,
    resetsAt: "2026-09-04T18:00:00Z"
  }],
  resetCredits?: {
    availableCount: 2,
    details?: [{ expiresAt, status }]
  },
  status: "ok" | "unsupported" | "error",
  fetchedAt: "…"
}
Percentages keep their meaningStore both provider value and display direction. Do not accidentally turn “used” into “remaining.”
Unknown is a valid stateMissing reset time, plan, or credits stays absent. We never manufacture a number.
Errors are per accountOne expired Claude login does not hide three healthy Codex accounts.
Identity is stableDedupe with provider account IDs when available; labels can change without creating duplicate cards.
05 · Build order

Prove the hard seams early.

Each phase ends with something runnable. The riskiest unknown—Cursor quota access—is isolated before it can distort the rest of the build.

0
Foundation
Package, CLI commands, localhost server, account registry, secret-store interface, adapter contract, fixtures.
Proof: one mocked card renders
1
Codex vertical
Add/list/remove accounts, isolated OAuth profiles, rate-limit reads, multi-bucket normalization, banked reset display.
Proof: two Codex accounts refresh
2
Claude vertical
Isolated CLI profiles, multi-account login, usage fetch, cache, expiry handling, schema fixtures and safe degradation.
Proof: stale token cannot crash server
3
OpenCode Go
Add/import keys, keychain storage, per-key usage request, rolling/weekly/monthly windows, dedupe rules.
Proof: two Go keys stay isolated
4
Cursor spike
Confirm active-account identity and authoritative quota source. Ship exact data if available; otherwise ship a clear unsupported state.
Proof: no guessed quota values
5
Product hardening
Manual refresh, bounded concurrency, timeouts, redacted diagnostics, responsive page, lifecycle cleanup, packaging.
Proof: npx just-usage
06 · Guardrails

Ship trust before features.

This tool handles high-value credentials. The safe failure mode is less data, never leaked data or confident fiction.

Must be true at launch

✓
No secrets in browser or logsSanitize commands, headers, stack traces, and raw provider bodies.
✓
No silent background pollingManual refresh; short provider-aware caches and backoff.
✓
Read-only quota productDisplay banked Codex resets, but do not redeem them in v1.
✓
Account lifecycle worksAdd, label, refresh, re-authenticate, and remove without orphaned secrets.

Known risks to contain

!
Claude endpoint driftFixture-based parser tests, feature detection, and one gray card on breakage.
!
Cursor may expose no quota APITime-box the spike; “signed in, quota unsupported” is an acceptable result.
!
Credential-store portabilityKeep a SecretStore interface; support platforms deliberately, never with a plaintext fallback.
!
Provider throttlingPer-account cache, bounded fan-out, retry only transient failures.

Start with Codex, design for every account.

The first vertical slice validates the whole architecture: connect, isolate, fetch, normalize, cache, render, remove. Claude and OpenCode Go then plug into proven seams.
